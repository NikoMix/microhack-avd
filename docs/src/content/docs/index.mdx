## What you build today

A single fictitious customer — **Contoso** — is migrating **~1,000 RDS/Citrix users** (knowledge
workers, a call centre, power users, and developers) to **Azure Virtual Desktop**. Across **eight
challenges** you take Contoso from **discovery → design → review → pilot → production → validation
→ handover**, exactly mirroring **Module B**, while a fleet of purpose-built **Copilot agents** and
**MCP servers** do the heavy lifting.

<Aside type="tip" title="Do it the agentic way">
  Every challenge leads with "ask the `avd-…` agent / use the `…` skill / query the `…` MCP", then
  shows the manual fallback. That contrast is the lesson.
</Aside>

## Quick start (learners)

<Steps>

1. **Open in Codespaces** — everything (`az`, `azd`, `bicep`, `terraform`, `gh`, Copilot CLI,
   `node`, `pwsh`, `python`) is pre-installed.

2. Set your `GH_TOKEN`, then `az login` to **your own** Azure subscription.

3. Start at **Challenge 00 · Setup & guardrails** and work the index above.

</Steps>

<Aside type="caution" title="Cost matters">
  Challenge 00 deploys a **budget + auto-shutdown** and uses small, teardownable SKUs. Run
  `scripts/reset/` at the end of the day — every challenge reminds you. The full 1,000-user
  footprint stays a **paper design**.
</Aside>

<Aside type="note" title="Aligned to the specialization">
  Derived from, and aligned to, the
  [AVD Advanced Specialization toolkit](https://github.com/NikoMix/specialization-avd) — it teaches
  the consulting engagement lifecycle the auditor inspects, accelerated with AI tooling. Every
  challenge produces a real **audit evidence artifact**.
</Aside>
