## Objective

Turn Contoso's on-premises **RDS + Citrix** estate into a defensible AVD workload assessment:
**personas**, an **application inventory** with a delivery decision per app, an **image strategy**,
and **host sizing/density** — framed with **MAP Toolkit / Azure Migrate** discovery.

## The agentic way (do this first)

- **Agent:** `avd-assessor`.
- **Skills:** `avd-personas-sizing` (sizing & density math), `avd-migration-cutover` (RDS/Citrix
  mapping), `avd-evidence-pack` (the `assessment.md` template).
- **MCP:** `microsoft-learn` to ground AVD host-pool and sizing guidance; `github` as the board.

## Evidence artifact

`assessment.md` — personas, app inventory + delivery decisions, image strategy, sizing/density,
and a MAP / Azure Migrate framing.

## Definition of done

- The four personas reconcile to **700 + 200 + 60 + 40 = 1,000**.
- Every application has a **delivery decision** (image, MSIX/app-attach, RemoteApp, retire…).
- An **image strategy** (single vs. per-persona golden image) is stated and justified.
- **Host sizing/density** is **calculated**, not guessed (VM family, users-per-host, IOPS).
- Discovery is framed against **MAP Toolkit / Azure Migrate / Citrix Director** data.

<Aside type="tip" title="Reconcile the numbers">
  An auditor checks arithmetic first. Make the persona counts, density math, and totals tie out
  before you write the narrative.
</Aside>
