Eight challenges take you through a complete **AVD Advanced Specialization Module B** engagement
for **Contoso**, using GitHub Copilot **agents, skills, and MCP servers** at every step. Each
challenge maps to a Module B control and produces the **evidence artifact** an auditor expects.

<Aside type="note" title="New here?">
  Read the **Overview** and **Scenario — Contoso** pages first (in the sidebar), then start at
  **Challenge 00**. Challenge prose lives in
  [`challenges/`](https://github.com/NikoMix/microhack-avd/tree/main/challenges) — this site links
  to each directory so you always get the latest.
</Aside>

## What each control must yield

| Control | Evidence the auditor expects |
|---|---|
| **B.1.1** Workload Assessment | Personas, app inventory + delivery decisions, image strategy, sizing/density, MAP/Azure Migrate |
| **B.2.1** Solution Design | High-Level Design (topology, identity, FSLogix, network, image, scaling, BCDR) |
| **B.2.2** Well-Architected Review | Cost / Performance / Reliability findings + decision register (AVD lens) |
| **B.2.3** PoC / Pilot | Scope, quantitative success criteria, results, go/no-go |
| **B.3.1** Deploy to Production | IaC pipeline run, config baseline, Go-Live record, cutover + rollback |
| **B.4.1** Service Validation | Logon perf, app launch, scaling, failover, FSLogix integrity test results |
| **B.4.2** Handover Docs | LLD, runbook, KT plan, hypercare plan, sign-off, lessons learned |

## How each challenge works

<Steps>

1. **Adopt the lead agent** (`avd-engagement-lead`) to orchestrate, or jump straight to the
   challenge's specialist agent.

2. **Do it the agentic way** — every challenge shows which **agent / skill / MCP** to use first,
   then a manual fallback.

3. **Produce the evidence** — copy the matching template from the `avd-evidence-pack` skill into
   the challenge's `work/` folder and fill it in.

4. **Pass the gate** — check your artifact against the **Definition of done** before moving on.

</Steps>

<Aside type="tip" title="Tracks">
  **IaC:** Challenges 05–06 run on either the **Bicep** or **Terraform** track — both deploy the
  same [landing zone](https://github.com/NikoMix/microhack-avd/tree/main/infra). **Footprint:**
  live deploys use a tiny lab slice (1–2 session hosts); Contoso's full ~1,000-user design stays
  on paper.
</Aside>
