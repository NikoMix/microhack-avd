## Objective

Validate the **deployed** AVD environment against the pilot's success criteria: **logon
performance**, **application launch**, **autoscaling behaviour**, **failover/resilience**, and
**FSLogix profile integrity** — capturing **pass/fail evidence**, not assertions.

## The agentic way (do this first)

- **Agent:** `avd-test-engineer`.
- **Skills:** `avd-fslogix` (profile integrity checks), `avd-personas-sizing` (expected density).
- **MCP:** `azure` (Monitor / AVD Insights / KQL) for measured results; `microsoft-learn` for the
  validation method.

## Evidence artifact

`validation.md` — measured results for logon, app launch, scaling, and failover, plus an FSLogix
profile round-trip, each marked **pass/fail** against the Challenge 04 criteria.

## Definition of done

- **Logon time** and **app-launch time** measured and compared to the pilot thresholds.
- **Autoscaling** behaviour observed (scale-out and scale-in) against the schedule.
- **Failover / resilience** exercised and the result recorded.
- **FSLogix** profile **round-trip** verified (sign in, persist, sign out, sign back in).
- Every result is **evidence** (numbers, screenshots, KQL) — not an assertion.

<Aside type="tip" title="Evidence, not assertion">
  "Logon averaged 18 s across 10 sign-ins (target ≤ 30 s) — PASS" is evidence. "Logon is fast"
  is not.
</Aside>
