# Solutions (trainer-only keys)

> ⚠️ **Trainers only.** Learners should attempt each challenge with the agents before looking
> here. These are reference answers, not the only correct answers.

One folder per challenge, each containing a **worked example of the evidence artifact** plus a
short rationale a trainer can teach from.

## Structure (target)

```text
solutions/
  challenge-00/   # setup verification + sample guardrail output
  challenge-01/   # sample assessment.md (worked)
  challenge-02/   # sample hld.md (worked, with diagram + decisions)
  challenge-03/   # sample waf-review.md (worked findings + decisions)
  challenge-04/   # sample pilot.md (worked criteria + results)
  challenge-05/   # sample deployment.md (what-if/plan + apply walkthrough)
  challenge-06/   # sample validation.md (worked results + KQL)
  challenge-07/   # sample handover pack (LLD, runbook, KT, hypercare, sign-off)
```

Each solution:

- Uses the **canonical scenario numbers** so it reconciles across the chain.
- Shows the **derivation** (sizing math, criteria rationale), not just the answer.
- Notes the **common ways learners go wrong** for the trainer to pre-empt.

Solution content is delivered by the challenge workstreams alongside each challenge.
